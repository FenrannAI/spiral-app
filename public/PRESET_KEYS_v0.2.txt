# HypnoVis Preset Keys — Quick Reference (v0.2)
# Flat list of every preset key, its type, valid range, and default.
# For full descriptions and structural notes see PRESET_SCHEMA_v0.2.txt.
#
# Format:  key  ·  type  ·  range  ·  default  ·  group
#
# BASE-ONLY fields (maxFps, plus sequencer metadata) live only at the top level
# of a preset/sequence — never inside a phase's `settings` object.
# All fields are optional; omit a key to keep its default.
