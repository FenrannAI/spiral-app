# HypnoVis Sequence JSON Generator Prompt
# Paste this file into any AI assistant to instruct it to generate a multi-phase sequence.

Sequencer Schema for HypnoVis sequences.
Generates a complete multi-phase animation journey.

type Transition = "linear" | "ease" | "pulse" | "spinBurst" | "fragment" | "inversionPulse";

interface Sequence {
  # ── Top-level / base-only fields (never inside a phase's settings) ──────────
  sequenceTitle: string;            # Name of this sequence journey
  sequencerLoop?: boolean;          # Loop back to Phase 1 [Default: true]
  sequencerEnabled?: boolean;       # Optional; set true to auto-arm on import
  maxFps?: number;                  # Optional base-only; 1–240 [Default: 144]
  sequencePhases: Phase[];          # Sequence steps in chronological order
}

interface Phase {
  id: string;                       # Simple short slug/identifier
  title: string;                    # UI phase label shown to user
  duration: number;                 # Hold time in seconds (e.g., 5 or 10)
  transitionType?: Transition;      # Transition style [Default: "linear"]
                                    #   linear    — constant rate
                                    #   ease      — slow-fast-slow
                                    #   pulse     — overshoots target then settles
                                    #   spinBurst — ease + extra rotation surge
                                    #   fragment  — ease + brings the Eyes effect in with a phase-offset surge
                                    #   inversionPulse — ease + full-screen inversion that
                                    #                flashes faster and faster (500ms→50ms)
                                    #                across the transition, overriding the
                                    #                normal inversion pulse until it completes
  transitionDuration?: number;      # Transition time in seconds [Default: 2]

  # settings is a REAL nested JSON object (NOT a string) holding this phase's
  # visual fields — any per-phase preset key (everything except the base-only
  # fields above). It is SELF-CONTAINED: include the fields you want this phase
  # to set; omitted fields use their DEFAULTS, never the previous phase's value.
  # No escaping, no deltas, no inheritance.
  settings: object;
}

# ── HOW TRANSITIONS WORK ─────────────────────────────────────────────────────
# Each AppState field falls into one of three categories during a transition:
#
# MOTION (continuously interpolated)
#   turns, curve, width, wobble*, colorCyclingSpeed, rotationSpeed, lineSpeed,
#   lineTime, textSize, flashIntensity, intenseStrobeDelay, strobeLength,
#   strobeIntensity, pulseMin, pulseMax, rampDuration, centerDotRadius,
#   inversionRate, inversionDuration, inversionIntensity,
#   fragmentPhaseOffset, eyeSpread, eyeSoftness,
#   hueRotation, hueRotateSpeed, armTaper,
#   vignetteIntensity, vignetteSize, vignetteSoftness,
#   audioVolume, audioCarrierFreq, audioBeatFreq, audioDroneLevel,
#   audioNoiseLevel, audioTremoloRate, audioTremoloDepth,
#   masterTempoBpm
#
# STRUCTURE (snapped at end of transition; never lerped)
#   arms, direction, gradientType, textAnimation, mode, spiralMath, colorMode,
#   kaleidoscopeSectors, strobeColorCount, rampMode,
#   fragmentDirectionMode, vignetteShape,
#   audioBeatMode, audioWaveform, audioDroneInterval, audioNoiseType,
#   lockColorCyclingRatio, lockHueRotateRatio, lockStrobeRatio,
#   lockInversionRatio, lockTextRatio,
#   lockSpeedRampRatio, lockAudioTremoloRatio, lockAudioBeatRatio,
#   masterTempoBeats,
#   lockStrobeBeat, lockInversionBeat, lockTextBeat
#
# SNAP (applied instantly at phase start)
#   textEnabled, flashEnabled, intenseFlash, pulseSpeed, randomOrder,
#   centerDotEnabled, all ramp*Speed toggles,
#   inversionEnabled, fragmentEnabled (Eyes),
#   vignetteEnabled,
#   audioEnabled, audioToneEnabled, audioDroneEnabled, audioNoiseEnabled,
#   rampAudioBeat,
#   masterTempoEnabled, masterTempoIndicator,
#   lockColorCycling, lockHueRotate, lockStrobe,
#   lockInversion, lockText, lockSpeedRamp, lockAudioTremolo, lockAudioBeat
#
# COLOR (interpolated)
#   color1, color2, color3, textColor, flashColor, centerDotColor,
#   strobeColor1, strobeColor2, strobeColor3,
#   vignetteColor

# ── SELF-CONTAINED PHASE FORMAT ──────────────────────────────────────────────
# Each phase's `settings` is a plain nested JSON object and stands on its own.
# Include the fields you want THIS phase to set; any field you omit takes its
# DEFAULT value — it does NOT inherit from the previous phase. There is no
# delta, no carry-over, no escaping.
#
# To keep a look or animate a value across phases, repeat the relevant fields in
# every phase. A MOTION or COLOR field only glides during a transition if BOTH
# the phase you leave and the phase you enter specify it — otherwise the missing
# side is its default. (E.g. to fade color1 across two phases, set color1 in both.)
#
# Base-only fields (maxFps) and sequencer metadata (sequencerEnabled,
# sequenceTitle, sequencerLoop) belong only at the top level — never in settings.

# ── PHOTOSENSITIVITY NOTE ────────────────────────────────────────────────────
# All users are presented with a full photosensitivity and hypnotic-effects
# warning modal on first load, and must agree before entering the app.
# Strobe, flash, and inversion effects are safe to include in generated
# sequences without additional caveats.

# ── MIX BOLDLY + USE MASTER TEMPO ────────────────────────────────────────────
# Great sequences layer effects aggressively and let phases evolve dramatically:
# shift spiralMath, swing direction, bring the Eyes effect in and out, deepen the
# vignette, ramp the speed, and move audio bands across the journey. When a phase
# runs more than one rhythmic effect (strobe, inversion, text, color cycling),
# enable Master Tempo and lock them to a shared BPM so the whole scene pulses on
# one beat — it is the most effective way to make a sequence feel intentional.

# ── RUNNING A GENERATED SEQUENCE (tell the user) ─────────────────────────────
# A pasted sequence does NOT auto-play. After importing the JSON, the user must:
#   1. Open the Sequencer tab.
#   2. Turn the sequencer on (the enable toggle at the top).
#   3. Press Play.
# (The app shows this reminder automatically when a sequence is imported.)

OUTPUT CONSTRAINTS:
1. Return ONLY a single raw valid JSON object.
2. Do not wrap in markdown or add explanations.
3. Every "settings" is a REAL nested JSON object — never an escaped string.
4. Each phase is SELF-CONTAINED: include the fields you want it to set; omitted
   fields use their defaults, NOT the previous phase's value. Repeat fields you
   want to persist or animate across phases.
5. Do not put base-only fields (maxFps, sequencerEnabled, sequenceTitle,
   sequencerLoop) inside a phase's settings.
6. Use spiralMath to choose the curve formula.
